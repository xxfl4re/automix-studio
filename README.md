AutoMix Studio
A music transition recommendation system built with Python and Arduino.
Overview
AutoMix Studio analyzes musical characteristics of two tracks and recommends a suitable transition method. It also explores Arduino-based lighting effects synchronized with music features.
Planned Features
- BPM and beat analysis
- Energy-based transition recommendations
- Python-to-Arduino serial communication
- Sensor-responsive LED effects
Tech Stack
- Python
- Arduino Uno R3
- C/C++ (Arduino firmware)
- Serial Communication
Project Status
Early development — features are planned and will be updated as they are implemented and tested.
